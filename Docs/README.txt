ОБЗОР
----------------------------------------------------------------

Парсер логов СХД Huawei OceanStor. Формирует Excel-отчёт
по форме ЗИП, а также предоставляет инструменты для 
детального анализа состояния оборудования.

Работает локально: без интернета, без установки, без внешних
сервисов. Только встроенный Python и шаблон Excel-формы.

Excel-отчёт содержит одну строку на СХД и по одной дочерней
строке на каждый уникальный компонент (группировка по типу
и BOM). В конец каждого блока СХД опционально добавляются
синтетические строки Memory и System Disk Drive.

ДЕТАЛЬНЫЙ АНАЛИЗ ОБОРУДОВАНИЯ
----------------------------------------------------------------
Помимо генерации отчётов, программа умеет проводить аудит
компонентов. Для запуска выберите лог или папку с логами 
и нажмите Инструменты -> Детальный анализ (или Ctrl+D).
  - Выбор компонентов для анализа (например, только BBU).
  - Автоматический расчет остатка срока службы батарей (BBU) 
    с учетом даты поставки (8 лет) на текущий день.
  - Цветовая индикация: красный (просрочено), оранжевый 
    (скоро конец срока).
  - Поддержка пакетного режима (анализ всех логов в папке).


БЫСТРЫЙ СТАРТ (GUI)
----------------------------------------------------------------

  1. Запустить Run.bat (двойной клик)
  2. Выбрать режим "Один файл" или "Папка (пакетно)"
  3. Нажать "Обзор" и выбрать .txt лог (или папку с логами)
  4. Нажать "Запустить"
  5. Excel-отчёт сохранится рядом с логом

  Горячие клавиши:
    F9             Запуск / Остановка
    Ctrl+O         Открыть лог-файл
    Ctrl+Shift+O   Открыть папку
    Ctrl+R         Открыть папку с результатом
    Ctrl+D         Детальный анализ оборудования
    F5             Self-test
    F1             Быстрый старт (эта справка)
    Ctrl+Q         Выход


КОНСОЛЬНЫЙ РЕЖИМ
----------------------------------------------------------------

  python Main.py                       Запуск GUI
  python Main.py log.txt               Один файл
  python Main.py C:\Logs               Все .txt в папке
  python Main.py --batch C:\Logs       Принудительный batch
  python Main.py --customer "Name"     Заказчик (колонка B)
  python Main.py --project  "Name"     Проект  (колонка C)
  python Main.py --help                Справка
  python Main.py --readme              Открыть README
  python Main.py --selftest            Self-test в консоли
  python Main.py --changelog           Открыть CHANGELOG


НАСТРОЙКИ
----------------------------------------------------------------

Открываются через Инструменты -> Настройки.

ОБЩИЕ
  Режим запуска
      Один файл / Папка (пакетно) / Последний использованный.
      Определяет, какой режим активен при запуске GUI.

  Папка по умолчанию для диалогов открытия
      Стартовая папка для "Обзор" и меню "Открыть...".
      Пусто = последняя открытая папка.

  Папка по умолчанию для экспорта
      Используется кнопкой "Экспорт".
      Пусто = последняя открытая папка.

  Всегда спрашивать место экспорта
      ВКЛ: каждый экспорт открывает диалог "Сохранить как",
           начиная с "Папки для экспорта" (или с последней
           открытой, если та пуста).
      ВЫКЛ: если папка задана — сохранение молча, без диалога.
            Если папка пуста — диалог всё равно появится.

ВЫВОД
  Автоматически открывать Excel после создания
      Если ВКЛ, отчёт открывается по завершении парсинга.

  Добавлять синтетические строки (Memory / System Disk Drive)
      Если ВКЛ, в конец каждого блока СХД добавляются две
      строки:
        - Memory              (см. Msg_Other/pangea_***)
        - System Disk Drive   (см. Msg_Other/scsi)
      Если ВЫКЛ, пишутся только реальные компоненты.

  Запрашивать Заказчика / Проект перед запуском
      Если ВКЛ, перед парсингом появляется диалог с двумя
      полями. Значения идут в колонки B и C отчёта.
      Отмена диалога прерывает запуск.

ДИАГНОСТИКА
  Очищать консоль при новом запуске
      Если ВКЛ, вкладка Console очищается в начале парсинга.

  Очищать таблицу Systems при новом запуске
      Если ВКЛ, таблица Systems очищается в начале парсинга.

  Подробный лог
      Если ВКЛ, в консоль выводятся дополнительные строки:
        - разбивка компонентов по типам
        - число уникальных BOM в Excel
        - итоги batch-обработки (всего / обработано /
          ошибок / время)

  Сбросить настройки
      Возвращает все значения по умолчанию. Ничего не
      сохраняется, пока не нажата кнопка "Сохранить".

ЯЗЫК
  Язык интерфейса: English / Русский.
  Смена языка предлагает перезапуск приложения.
  Строки отчёта (TEXT_MEMORY, описания категорий и т.п.)
  всегда остаются на русском — это данные, а не UI.


ЭКСПОРТ
----------------------------------------------------------------

Кнопка "Экспорт" внизу главного окна. По клику открывается
меню:

    Консоль -> .txt       Экспорт вкладки Console
    Системы -> .csv       Экспорт таблицы Systems

После экспорта появляется диалог с кнопкой "Открыть папку",
которая открывает папку с сохранённым файлом.

CSV:
  - Кодировка: UTF-8 с BOM (Excel открывает корректно)
  - Разделитель: точка с запятой ( ; )
  - Заголовки: названия колонок из таблицы Systems


ОПИСАНИЕ ОТЧЁТА
----------------------------------------------------------------

Excel-отчёт следует форме ЗИП (лист "ЗИП").

  Колонка A   Номер строки (1, 1.1, 1.2, ...)
  Колонка B   Заказчик в CRM2 (опционально)
  Колонка C   Проект CRM2 (опционально)
  Колонка F   Наименование системы
  Колонка G   Вендор (всегда Huawei)
  Колонка H   Модель оборудования
  Колонка I   Серийный номер
  Колонка J   Part number оборудования
  Колонка K   Наименование компонента (из Electronic Label)
  Колонка L   Категория (Storage, Controller, Disk Drive, ...)
  Колонка M   Part number (BOM)
  Колонка N   Комментарий (для SFP без BOM в логе)
  Колонка O   Количество на единицу
  Колонка P   Необходимо в ЗИП (по умолчанию 1)
  Колонка R   Формула отклонения =P - Q


РЕШЕНИЕ ПРОБЛЕМ
----------------------------------------------------------------

"Описание отсутствует, требуется проверка в Spare Query"

  Electronic Label для этого компонента пуст в логе. Парсер
  честно сообщает, что не может извлечь описание. Смотрите
  полное название в Spare Query.


"Unsupported system version"

  Лог относится к неподдерживаемой версии. Поддерживаются:
  V6, V5, V3. Проверьте строку "Product Model:" в шапке лога.


Self-test показывает FAIL

  Откройте Инструменты -> Self-test (F5). Частые причины:
    - отсутствует шаблон Form.xlsx;
    - отсутствуют модули парсера;
    - не установлен openpyxl / PyQt6.


Ошибка "пустая папка" в batch-режиме

  Batch требует хотя бы один .txt файл в выбранной папке.


Экспорт сохраняется не в ту папку

  Проверьте настройки:
    - Папка по умолчанию для экспорта
    - Всегда спрашивать место экспорта
  Если "Всегда спрашивать" ВЫКЛ и папка задана — файлы
  сохраняются молча в эту папку.


СТРУКТУРА ПРОЕКТА
----------------------------------------------------------------

  Main.py                 Главная точка входа (GUI / консоль)
  Run.bat / Run.sh        Скрипты запуска для Windows / Linux
  Form.xlsx               Шаблон Excel-отчёта (форма ЗИП)

  Core/                   Ядро парсера (логика и диспетчеризация)
    Core_Base_Parser.py   Выбор парсера по версии
    Core_System_Info.py   Разбор шапки лога (SUMMARY)
    Export_Excel.py       Генератор Excel-отчёта

  Parsers/                Модули парсинга для разных поколений
    Parser_V3.py          Парсеры V3
    Parser_V5.py          Парсеры V5
    Parser_V6.py          Парсеры V6

  GUI/                    Интерфейс на PyQt6
    Gui_App.py            Главное окно и диалоги
    Gui_Main.py           Запуск GUI-приложения
    Gui_Settings.py       Окно настроек
    Gui_Workers.py        Фоновые потоки (Сборка Excel, Быстрое превью)

  Utils/                  Вспомогательные модули
    Utils_Constants.py    Константы (версия, колонки, категории)
    Utils_Locale.py       Локализация интерфейса (RU / EN)
    Utils_Regex_Helpers.py Хелперы для регулярных выражений
    Utils_SelfTest.py     Логика Self-test
    Utils_System.py       Системные вызовы (открытие файлов/URL)

  Docs/                   Документация
    README.txt            Быстрый старт (этот файл)
    CHANGELOG.txt         История версий
    USER_GUIDE.txt        Подробное руководство пользователя

Поток данных:

  лог .txt
     |
     v
  Main.py (или GUI -> Gui_Workers)
     |
     v
  Core/Base_Parser
     |
     +--> Core/System_Info (определение версии)
     |
     +--> выбор парсера (V3 / V5 / V6)
     |        |
     |        v
     |    Parsers/Parser_Vx -> [{id, name, type, bom}, ...]
     |
     v
  Core/Export_Excel
     |
     +--> копия Form.xlsx
     +--> заполнение листа "ЗИП"
     v
  HuaHW-Tracker_<name>_<timestamp>.xlsx
