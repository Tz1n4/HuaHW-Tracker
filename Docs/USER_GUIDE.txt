ОБЗОР
----------------------------------------------------------------

Инструмент для анализа логов оборудования Huawei (СХД OceanStor/Dorado). 
Читает .txt лог, определяет версию (V3 / V5 / V6), разбирает 
компоненты и формирует Excel-отчёт по форме ЗИП на основе Form.xlsx.

В отчёт попадают:
  - корневая строка на каждую СХД;
  - дочерние строки на каждый уникальный компонент
    (группировка по типу и BOM);
  - опционально две синтетические строки в конце блока СХД:
    Memory и System Disk Drive.

Помимо отчётов, программа предоставляет инструмент «Детальный
анализ» для аудита состояния компонентов (например, батарей BBU).

Работает локально: без интернета, без установки, только
встроенный Python и шаблон Excel-формы.

История версий: CHANGELOG.txt
Быстрый старт:  README.txt


ПОДДЕРЖИВАЕМЫЕ СИСТЕМЫ
----------------------------------------------------------------

  V6  - OceanStor Dorado 3000 / 5000 / 6000 / 8000
  V5  - OceanStor 2600 / 5110 / 5210 / 5300 / 5500 / 5600 V5
  V3  - OceanStor 5300 / 5500 / 5600,
        OceanStor Dorado 5000 / 6000

Определение версии — по трём источникам, в порядке приоритета:

  1) Product Model в шапке
       "OceanStor Dorado 8000 V6"  ->  V6
       "OceanStor 5500 V5"         ->  V5

  2) Product Version в шапке
       "V600R005C27"               ->  V6
       "V500R007C20"               ->  V5

  3) Маркеры в теле лога
       "Control Board("                          ->  V6
       "Enclosure Info" + "Electronic Label" +
       "Controller ID:"                          ->  V5
       "Controller ID:" + "sfp info:"            ->  V3

Если версия не распознана — "Unsupported system version".


УСТАНОВКА И ЗАПУСК
----------------------------------------------------------------

Требования:
  - Windows (основная платформа);
  - Python 3.12.7 (встроенный, папка python-3.12.7-embed-amd64);
  - пакеты openpyxl и PyQt6.

Запуск GUI:              Run.bat (двойной клик)
Запуск GUI из консоли:   python Main.py
Один файл:               python Main.py log.txt
Все .txt в папке:        python Main.py C:\Logs

Run.bat использует встроенный Python. Команда python Main.py
использует Python из PATH.

ДЕТАЛЬНЫЙ АНАЛИЗ ОБОРУДОВАНИЯ
----------------------------------------------------------------

Инструменты -> Детальный анализ (Ctrl+D).
Открывает окно продвинутого анализа компонентов. 
Работает как для одного файла, так и для всей папки (пакетно).

Возможности:
  1. Выбор компонентов. Нажмите "Выбрать компоненты...", 
     чтобы отметить галочками только те узлы, которые нужно 
     проверить (например, только BBU). Выбор сохраняется 
     между запусками программы.
  2. Вкладки. Результаты по каждому типу компонентов 
     открываются на своей вкладке (например, 🔋 BBU).
  3. Сортировка. Клик по заголовку колонки сортирует данные 
     (например, по остатку дней).
  
Анализ BBU (батарей):
  - Показывает ID слота, текущее состояние (Health/Running), 
    напряжение и версию прошивки.
  - Рассчитывает реальный остаток срока службы (в днях) 
    на основе даты поставки (Delivered On) и норматива в 8 лет 
    (2920 дней) на момент сегодняшнего дня.
  - Показывает "Возраст" батареи (сколько времени прошло 
    с момента поставки).
  - Цветовая подсветка: 
      Красный  - ресурс исчерпан (остаток < 0).
      Оранжевый - осталось менее 180 дней.


КОМАНДНАЯ СТРОКА (CLI)
----------------------------------------------------------------

  python Main.py log.txt                один файл
  python Main.py C:\Logs                все .txt в папке
  python Main.py --batch C:\Logs        принудительный batch

  python Main.py log.txt --customer "ПАО Ростелеком" \
                        --project  "ЦОД-МСК-2026"
  python Main.py C:\Logs --customer "ПАО Ростелеком" \
                         --project  "ЦОД-МСК-2026"

  python Main.py --help, -h             справка
  python Main.py --readme               открыть README
  python Main.py --changelog            открыть CHANGELOG
  python Main.py --selftest             Self-test

Порядок аргументов не важен. --customer / --project работают
в обоих режимах. Путь к папке автоматически включает batch.


СПРАВОЧНИК НАСТРОЕК
----------------------------------------------------------------

Инструменты -> Настройки...

ОБЩИЕ
  Режим запуска
      Один файл / Папка (пакетно) / Последний
      использованный. По умолчанию: Последний
      использованный.

  Папка по умолчанию для диалогов открытия
      Стартовая папка для "Обзор" и "Файл -> Открыть".
      Пусто = последняя открытая.

  Папка по умолчанию для экспорта
      Куда сохраняются .txt / .csv. Пусто = последняя
      открытая.

  Всегда спрашивать место экспорта
      ВКЛ  - диалог "Сохранить как" при каждом экспорте.
      ВЫКЛ - если папка экспорта задана, сохраняется молча.

  Язык
      English / Русский. По умолчанию: Русский.
      Смена языка предлагает перезапуск.

ВЫВОД
  Автоматически открывать Excel после создания
      ВКЛ / ВЫКЛ (по умолчанию ВЫКЛ).

  Добавлять синтетические строки (Memory / System Disk Drive)
      ВКЛ - две строки в конце каждого блока СХД.
      ВЫКЛ (по умолчанию) - только реальные компоненты.

  Запрашивать Заказчика / Проект перед запуском
      ВКЛ (по умолчанию) - диалог с двумя полями перед
      каждым запуском. Отмена прерывает запуск.
      ВЫКЛ - колонки B и C остаются пустыми (если не заданы
      через --customer / --project).

ДИАГНОСТИКА
  Очищать консоль при новом запуске
  Очищать таблицу Systems при новом запуске
  Подробный лог (Verbose logging)
      ВКЛ - разбивка компонентов по типам, число
      уникальных BOM, итоги batch-обработки.
  Сбросить настройки
      Возвращает все значения по умолчанию. Ничего не
      сохраняется до нажатия Сохранить.


ЭКСПОРТ
----------------------------------------------------------------

Кнопка 📤 Экспорт внизу главного окна:

  📄 Консоль -> .txt    содержимое вкладки Консоль
  📊 Системы -> .csv    таблица Системы

CSV:
  - кодировка UTF-8 с BOM (Excel открывает корректно);
  - разделитель — точка с запятой ( ; );
  - заголовки — названия колонок таблицы Системы.

После экспорта — диалог с кнопкой "Открыть папку".

Поведение:
  ВКЛ  -> диалог "Сохранить как" (старт в папке экспорта).
  ВЫКЛ и папка задана     -> сохранение молча.
  ВЫКЛ и папка НЕ задана  -> диалог всё равно появится.

Имя файла: console_20261014_153012.txt
           systems_20261014_153045.csv


СТРУКТУРА EXCEL-ОТЧЁТА
----------------------------------------------------------------

Форма ЗИП (лист "ЗИП") на основе Form.xlsx.

  A   Номер строки: 1 — корневая, 1.1 / 1.2 / ... — дочерние.
  B   Заказчик в CRM2          (диалог или --customer)
  C   Проект CRM2              (диалог или --project)
  F   Наименование оборудования (System Name)
  G   Вендор                   (всегда Huawei)
  H   Модель                   (Product Model)
  I   Серийный номер           (Product Serial Number)
  J   Артикул оборудования     (SN[2:10])
  K   Наименование ЗИП         (Description из Elabel,
                                или Vendor Model для SFP)
  L   Тип ЗИП                  (Storage / Controller /
                                Disk Drive / Блок Питания /
                                Батарея / Fan / I/O Module /
                                Expansion Board / SFP / Memory /
                                Data Switch)
  M   Part Number ЗИП          (Item из Elabel; для SFP без
                                BOM — пусто)
  N   Комментарий              (для SFP без BOM)
  O   Количество на ЕДИНИЦУ
  P   Необходимо в ЗИП         (по умолчанию 1)
  Q   Кол-во на складах        (вручную)
  R   Отклонение               (=P{row}-Q{row})

Порядок дочерних строк:
  Controller, Disk, Disk Enclosure (DAE), Data Switch,
  Power Supply, BBU, Fan, I/O Module, Expansion Board,
  SFP Module, Memory, System Disk Drive.

ГЛОССАРИЙ
----------------------------------------------------------------

  ЗИП           Запасные части, инструменты и принадлежности.
  CRM2          Система учёта (заказчик / проект).
  BOM           Bill of Materials, артикул компонента.
  Elabel        Electronic Label — блок в логе с полями
                Description / BarCode / Item.
  SN            Serial Number, серийный номер.
  CTE0          Controller Enclosure 0 (основная полка).
  DAE           Disk Array Enclosure (полка с дисками).
  DSW           Data Switch.
  PSU           Power Supply Unit, блок питания.
  BBU           Battery Backup Unit, батарейный модуль.
  IOM           I/O Module, модуль ввода-вывода.
  SFP           Small Form-factor Pluggable, оптический
                трансивер.
  V3 / V5 / V6  Поколения прошивок Huawei OceanStor.
  Дамп          Лог-файл, снятый с СХД командой сбора
                диагностики.


РЕШЕНИЕ ПРОБЛЕМ
----------------------------------------------------------------

1) "Описание отсутствует, требуется проверка в Spare Query"

   Блок Electronic Label для компонента пуст в логе. Парсер
   честно сообщает, что не может извлечь описание.
   Проверьте полное название вручную в Spare Query.

2) "Unsupported system version"

   Лог относится к неподдерживаемой версии (V6, V5, V3).
   Проверьте строку "Product Model:" в шапке лога.

3) Self-test показывает FAIL

   Инструменты -> Self-test... (F5) покажет, какая проверка
   не прошла. Частые причины:
     - отсутствует Form.xlsx;
     - отсутствуют модули парсера;
     - не установлены openpyxl / PyQt6.

4) Пустая папка в batch-режиме

   Нужен хотя бы один .txt файл в выбранной папке.

5) Экспорт сохраняется не в ту папку

   Проверьте "Папка по умолчанию для экспорта" и
   "Всегда спрашивать место экспорта". Если ВЫКЛ и папка
   задана — файлы сохраняются молча туда.

6) После смены языка интерфейс не поменялся

   Язык применяется после перезапуска. При смене языка
   появляется диалог с предложением перезапуститься.

7) Кнопка "▶ Запустить" неактивна

   Проверьте выбранный путь: .txt файл в режиме "Один файл"
   или папка с .txt логами в режиме "Папка (пакетно)".

8) Excel не открывается автоматически

   Настройки -> Вывод -> "Автоматически открывать Excel
   после создания" = ВКЛ. По умолчанию ВЫКЛ.

9) Галочки компонентов в «Детальном анализе» сбрасываются

   Убедитесь, что программа закрыта корректно. Настройки
   сохраняются при выходе. Если проблема сохраняется,
   удалите файл Settings.ini в корне проекта (он создастся
   заново с настройками по умолчанию).
