================================================================  HUAWEI STORAGE LOG PARSER  Версия 18.0================================================================ОБЗОР----------------------------------------------------------------Парсер логов СХД Huawei OceanStor. Формирует Excel-отчётпо форме ЗИП.Работает локально: без интернета, без установки, без внешнихсервисов. Только встроенный Python и шаблон Excel-формы.Excel-отчёт содержит одну строку на СХД и по одной дочернейстроке на каждый уникальный компонент (группировка по типуи BOM). В конец каждого блока СХД опционально добавляютсясинтетические строки Memory и System Disk Drive.Полная история версий: CHANGELOG.txtПОДДЕРЖИВАЕМЫЕ СИСТЕМЫ----------------------------------------------------------------  V6  - OceanStor Dorado 3000 / 5000 / 6000 / 8000  V5  - OceanStor 2600 / 5110 / 5210 / 5300 / 5500 / 5600 V5  V3  - OceanStor 5300 / 5500 / 5600,        OceanStor Dorado 5000 / 6000БЫСТРЫЙ СТАРТ (GUI)----------------------------------------------------------------  1. Запустить Run.bat (двойной клик)  2. Выбрать режим "Один файл" или "Папка (пакетно)"  3. Нажать "Обзор" и выбрать .txt лог (или папку с логами)  4. Нажать "Запустить"  5. Excel-отчёт сохранится рядом с логом  Горячие клавиши:    F9             Запуск / Остановка    Ctrl+O         Открыть лог-файл    Ctrl+Shift+O   Открыть папку    Ctrl+R         Открыть папку с результатом    F5             Self-test    F1             Быстрый старт (эта справка)    Ctrl+Q         ВыходКОНСОЛЬНЫЙ РЕЖИМ---------------------------------------------------------------- По клику открываетсяменю:    Консоль -> .txt       Экспорт вкладки Console    Системы -> .csv       Экспорт таблицы SystemsПосле экспорта появляется диалог с кнопкой "Открыть папку",которая открывает папку с сохранённым файлом.CSV:  - Кодировка: UTF-8 с BOM (Excel открывает корректно)  - Разделитель: точка с запятой ( ; )  - Заголовки: названия колонок из таблицы SystemsОПИСАНИЕ ОТЧЁТА----------------------------------------------------------------Excel-отчёт следует форме ЗИП (лист "ЗИП").  Колонка A   Номер строки (1, 1.1, 1.2, ...)  Колонка B   Заказчик в CRM2 (опционально)  Колонка C   Проект CRM2 (опционально)  Колонка F   Наименование системы  Колонка G   Вендор (всегда Huawei)  Колонка H   Модель оборудования  Колонка I   Серийный номер  Колонка J   Part number оборудования  Колонка K   Наименование компонента (из Electronic Label)  Колонка L   Категория (Storage, Controller, Disk Drive, ...)  Колонка M   Part number (BOM)  Колонка N   Комментарий (для SFP без BOM в логе)  Колонка O   Количество на единицу  Колонка P   Необходимо в ЗИП (по умолчанию 1)  Колонка R   Формула отклонения =P - QРЕШЕНИЕ ПРОБЛЕМ----------------------------------------------------------------"Описание отсутствует, требуется проверка в Spare Query"  Electronic Label для этого компонента пуст в логе. Парсер  честно сообщает, что не может извлечь описание. Смотрите  полное название в Spare Query."Unsupported system version"  Лог относится к неподдерживаемой версии. Поддерживаются:  V6, V5, V3. Проверьте строку "Product Model:" в шапке лога.Self-test показывает FAIL  Откройте Инструменты -> Self-test (F5). Частые причины:    - отсутствует шаблон Form.xlsx;    - отсутствуют модули парсера;    - не установлен openpyxl / PyQt6.Ошибка "пустая папка" в batch-режиме  Batch требует хотя бы один .txt файл в выбранной папке.Экспорт сохраняется не в ту папку  Проверьте настройки:    - Папка по умолчанию для экспорта    - Всегда спрашивать место экспорта  Если "Всегда спрашивать" ВЫКЛ и папка задана — файлы  сохраняются молча в эту папку.СТРУКТУРА ПРОЕКТА----------------------------------------------------------------  Main.py                 Точка входа (GUI / консоль)  Gui_App.py              Главное окно  Gui_Main.py             Запуск GUI  Gui_Settings.py         Диалог настроек  Gui_Workers.py          QThread-воркеры  Core_Base_Parser.py     Диспетчер (выбор парсера по версии)  Core_System_Info.py     Разбор шапки лога, определение версии  Parser_V3.py            Парсер V3 (Dorado + OceanStor)  Parser_V5.py            Парсер V5 (2600 / 5110 / 5x00 V5)  Parser_V6.py            Парсер V6  Export_Excel.py         Генератор Excel-отчёта  Utils_Constants.py      Константы, индексы колонок, категории  Utils_Regex_Helpers.py  Regex-хелперы  Utils_System.py         Системные вызовы (открытие файлов,                          папок, URL)  Utils_SelfTest.py       Логика Self-test  Utils_Locale.py         Локализация UI (EN / RU)  Form.xlsx               Шаблон Excel  README.txt              Этот файл  CHANGELOG.txt           История версий  Run.bat                 Запуск для Windows  Run.sh                  Запуск для Linux / macOSАВТОР----------------------------------------------------------------  Баринштейн Даниил  Telegram: @Tz1n4  (c) 2026================================================================
